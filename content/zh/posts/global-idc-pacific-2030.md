几家投行的数据中心测算放在一起看，会得到一个很反直觉的结论：**这一轮 AI 基建的瓶颈，已经不是「有没有钱建」，而是「建好了有没有电」。**

我把它做成了一个可以拖着看的交互看板（[点这里打开](https://liweicong2016-collab.github.io/my-website/articles/global-idc-pacific-2030.html)），下面是文字版的判断。

## 一、先把存量看清楚

2026 年底，全球 IT 容量大约 **136 GW**（摩根士丹利口径，SemiAnalysis 估 113 GW）。

拆开看：

```
美国      63 GW   46%
中国      31 GW   23%
日韩       9 GW    7%
欧洲      10 GW    7%
东南亚     3 GW    2%
其他      20 GW   15%
```

**美国 + 中国 = 接近七成。**

这个集中度比很多人想的要高。讨论「全球算力」的时候，实际上是在讨论两个国家。

2026 年全球新增 25 GW，高盛和 SemiAnalysis 在这个数上是一致的。

## 二、2030 年的分歧，比数字本身更重要

```
高盛         273 GW
摩根士丹利   316 GW
```

**差 43 GW，相当于 2026 年全球存量的三分之一。**

分歧主要出在 2027 年：

```
高盛 / 大摩      约 32 GW 新增
SemiAnalysis     中国以外 51.2 GW（乐观值）
                 其中约 11.9 GW 仍处规划状态
```

**同一年的同一个市场，两家差了 60%。** 这不是模型精度的问题，是对「审批能不能过」的判断不同。

## 三、2028 才是分水岭

2027 年及以前投运的项目，绝大多数已经拿到批文和电力接入，政策变化基本动不了。

**真正的风险在 2028 年以后。**

我 11 月写过一篇关于美国中期选举如何卡住算力的（[那篇在这里](https://liweicong2016-collab.github.io/tech-blog/posts/ai-compute-election-bottleneck-2026/)），核心数字是：2028 年计划新增的 62.2 GW 里，**93% 连土都没动**。

现在的口径是：

```
全部规划（AI 训练类）   148 GW
已获批 / 在建            88 GW
待审批                   60 GW   ← 40%
最坏情景：直接取消       12 GW   ← 占全部规划 8%
```

三家机构的风险量级：

```
Susquehanna   2028–2030 约 12 GW 可能被取消
摩根士丹利     得州 + 俄亥俄约 12.4 GW 面临延期
瑞银           美国 2028 年约 30% 计划新增可能受暂停影响
```

**三种测算的方法不一样，但都指向同一个量级：十几 GW，相当于 2026 年全球新增的一半。**

## 四、东南亚：地图上的 3 GW，拆开是另一回事

这是我看这份数据时最想说的一段。

看板上东南亚只是一个小绿点，3 GW。但把它拆成三个国家，会看到两件完全不同的事。

**第一件：存量确实就这么点。**

```
泰国     0.77 GW（2025，IT 负载）
马来     1.11 GW（2026H1，柔佛占全国约 80%）
印尼     运营商存量几十 MW 级
```

加起来约 1.9–2.2 GW，加上越南、新加坡，和「东南亚 3 GW」基本对得上。

**第二件：管道是存量的四倍以上。**

```
马来     运营 1,110 MW + 在建 602 MW + 管道 8,542 MW
泰国     2030 年 2.93 GW（CAGR 30.6%）
印尼     2034 年电力管道 25,297 MW
```

**但这里有个必须说清楚的口径陷阱。**

印尼那个 25,297 MW 是**电力管道**，不是 IT 容量。按 IT 负载通常低于设施容量 30–40% 换算，实际可部署的算力远小于这个数。把它和 IT 容量放在一张表里相加，会得出荒谬的结果。

我把它做成了一张对照表，放在看板里，就是为了防止自己以后引用时犯错。

**第三件，也是最重要的：三国卡在同一个地方。**

```
泰国   电力接入申请 35 GW，接近全国 40 GW 峰值需求
       而 PDP 只规划了 8.8 GW 的数据中心配套电力
印尼   现有并网接入 1,990.5 MVA
       2027–2028 要集中接入 6,884 MW 和 7,798 MW
马来   2027 年是明确的电力硬约束
```

**不是没钱，不是没地，不是没客户——是电送不进去。**

这三个国家的数字经济增速、外资流入、政策优惠都在往上走，但电网和并网审批的速度跟不上数据中心的建设速度。

## 五、三个判断

**① 供给受限 ≠ 需求消失，但它会改变谁赚钱**

成本上升 10%–20% 的同时，可交付的算力变少了。**这对已经建成投产的算力持有者是利好**——存量资产的定价权反而上升。

**对还在建的是利空**，因为你的成本在涨，交付时间在推后，而客户已经等不及了。

**② 最值得跟踪的信号，不是 GW 数字，是上游砍单**

如果 2028 年的审批真的卡住，最先反映的不是数据中心的空置率，是 **GPU 和光模块的订单被砍、EPS 被下修**。

**这两个东西的交付周期是 6–12 个月，比机房快得多。所以它们是更早的预警指标。**

**③ 「规划」这个词，在这份数据里已经贬值了**

148 GW 规划里，60 GW 还在审批。**换句话说，我们讨论的「未来算力」，有 40% 还只是一张纸。**

任何拿「规划总量」做测算的报告，都应该先扣掉这 40%。

## 六、最后

把这几个数字放在一起，我最大的感受是：

**过去两年我们讨论 AI 的瓶颈，顺序是「芯片 → 电力 → 电网」，现在这个顺序可能要倒过来。**

芯片的产能正在爬坡，HBM 也在扩产；但一个 500 MW 的数据中心从拿地到通电，在美国要 3–5 年，在东南亚很多地方更久。

**算力是能造出来的，电是等出来的。**
